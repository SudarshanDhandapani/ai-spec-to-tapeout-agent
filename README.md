# AI-Assisted Spec-to-Tapeout Agent

![Python](https://img.shields.io/badge/Python-3.11-blue)
![AI](https://img.shields.io/badge/AI-LLM-green)
![EDA](https://img.shields.io/badge/EDA-RTL--to--GDSII-orange)

An AI-assisted RTL generation and verification framework that transforms high-level design specifications into verified synthesizable Verilog using semantic IR, automated testbench generation, simulation, and feedback-driven repair.

---

## Highlights

- AI-assisted RTL generation
- Semantic Intermediate Representation (IR)
- Automatic testbench generation
- Compile and simulation verification
- Feedback-driven RTL repair
- Verification report generation
- End-to-end RTL automation
